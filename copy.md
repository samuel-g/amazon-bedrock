# Amazon Bedrock and Streamlit: Overview Notes

## Amazon Bedrock
- A **fully managed AWS service** for using **foundation models (FMs)**.
- Gives access to models from **Amazon and third-party providers**.
- Offers **one set of APIs** for both:
  - **Text generation**
  - **Image generation**

## The Workshop
- **Language:** Python
- **Goal:** Build **generative AI prototypes** using Amazon Bedrock.
- **Format:** A series of **labs** that go from **beginner to intermediate**.
- **What you learn:** How to use the libraries and models to build prototypes for **many different use cases**.

## Streamlit
- A Python library for building **web front ends** quickly.
- You **don't need front-end skills** such as HTML, CSS or JavaScript.
- Good for **proofs of concept (POCs)**.
- Makes demos easy to show to **technical and non-technical audiences**.

## Workshop Flow
1. Finish the **Prerequisites** sections first.
2. After that, you can do the labs **in any order**.

## Key Takeaways
- **Bedrock** is the AI backend: models through one API.
- **Streamlit** is the UI layer: fast Python web apps.
- **Python** connects the two.
- Together they let you **build and show GenAI prototypes quickly**.
